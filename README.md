A small Python entry for the "One Line, One Laugh" bounty on make.fun. `main.py` (Python 3, standard library only) writes a single line to `/output/entry.txt`, and an AI judge compares entries pairwise on how funny they are. The line: "After my third wrong turn, my GPS said 'recalculating' with such patience that I could hear a machine learning to lower its expectations."

## Run it
```sh
python3 main.py
```
